# 📚 Sistema MVC Simples em PHP

Projeto desenvolvido para estudo da arquitetura MVC utilizando:
- PHP
- MySQL
- HTML
- CSS
- JavaScript

---

# 🎯 Objetivo

O objetivo do projeto é demonstrar de forma simples como funciona a separação de responsabilidades utilizando o padrão MVC (Model-View-Controller).

---

# 🧠 Conceitos aplicados

## Model
Responsável pelos:
- dados
- regras de negócio
- acesso ao banco

## View
Responsável pela:
- interface
- exibição de dados

## Controller
Responsável por:
- controlar o fluxo
- receber requisições
- conectar Model e View

---

# 🛠️ Tecnologias

- PHP
- MySQL
- HTML
- CSS
- JavaScript

---

```txt
app/
```

# ⚙️ Funcionalidades

- Cadastro de usuários
- Listagem de usuários
- Validação simples com JavaScript
- Integração com MySQL

---

# 🚀 Objetivo educacional

Este projeto foi criado para:
- estudar MVC
- compreender fluxo backend
- praticar organização de código
- entender integração entre front-end e back-end
